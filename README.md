# JLPT N5｜30 天情境閱讀計畫

這是一套以短文、故事與對話為核心的 JLPT N5 學習專案。

目標不是背誦彼此獨立的例句，而是在 30 天內透過約 330～360 句、螺旋式重複的日文材料，建立 N5 核心單字、文法與閱讀直覺。

## 學習設計

- 30 篇課程，一天一篇
- 每篇約 10～12 個日文句子
- 每篇以 1～3 個主要新文法為原則
- 新單字控制在合理範圍，並持續重複舊單字
- 混合短篇敘事、情境對話和描述文
- Day 28～30 以整合閱讀為主，不大量增加新內容
- 所有說明均使用繁體中文

完成 30 天代表完成 N5 核心內容的第一輪，而不是保證所有內容已永久記住。之後會在 N4 閱讀中繼續複習與鞏固 N5。

## 專案內容

```text
curriculum/             30 天課程藍圖
lessons/n5/             每日正式課程
questions/              文法、單字和句子問題
reviews/                易錯點與每週複習
resources/              累積式詞彙與文法索引
templates/              課程和問題紀錄模板
PROJECT_CONTEXT.md      專案背景與已確認決策
AGENTS.md               與 Codex 協作時使用的規則
```

## 每日使用方式

1. 先讀日文正文，不看翻譯。
2. 標記看不懂或不確定的句子。
3. 查看翻譯、單字、語塊與文法解析。
4. 回答理解題，完成簡短造句。
5. 把實際遇到的疑問補入該課，跨課共通問題再整理到 `questions/`。
6. 更新學習進度和易錯點。
