# N5 課文編寫

## 讀取依據

以專案根目錄為工作目錄。先讀 [AGENTS.md](../../AGENTS.md)、[專案背景](../../PROJECT_CONTEXT.md)、[課程藍圖](../../curriculum/n5-roadmap.md)與[課程模板](../../templates/lesson-template.md)。數量與每日目標以藍圖為準，不在此維護第二份配置。

讀取目標課次、實際存在的前課、[文法索引](../../resources/grammar-index.md)、[單字索引](../../resources/glossary.md)及[易錯點](../../reviews/mistakes.md)。只針對當課需要追溯相關課文與問題，避免一次讀取所有學習紀錄。

## 從配置到正文

1. 確認使用者指定的課次；「下一課」以實際教材及對話進度判定，不把已產生教材視為已學完。建立 `lessons/n5/day-NN.md`；若檔案已存在，先讀再修改。
2. 列出當課溝通目標、新文法、新詞與回收項目。先備知識以已寫成課文為證據，藍圖中的預定內容不算已教。若前課未寫而使用者指定後課，列明先備假設，不自動生成所有前課。
3. 在工作筆記中逐句配置「情境作用／主要新文法／新詞／舊知識來源」，再寫成連貫正文。這份編寫筆記不必塞入學習者課文。
4. 以一個編號對應一個正文句子，對話標示說話者，翻譯使用相同編號。固定招呼若獨立成句也計入；不要把多個完整句子合併一號來符合句數。
5. 新詞以辭書形去重；人名與已學詞的活用不另算新詞。不能為壓低數量把陌生詞改標為舊詞。未教句型優先改寫；必要招呼可標「固定語塊，暫不拆解」，並安排後續拆解。
6. Day 01沒有舊課，在「舊知識回顧」說明起點與假名準備即可，不虛構前課。Day 28～30的新文法區說明本課整合哪些已學句型。

## 解說與練習

- 使用模板的十個區塊。文法先說本文中的意思，再說接續、本文句號與使用提醒；一個句型的其他用法只在有助當課時補充。
- 翻譯忠於人物、肯否、時間及語氣；中文可自然改寫，但不補入正文沒有的事實。
- 理解題需能由正文回答；避免題目本身要求尚未教的日文。產出練習接受多個自然答案，清楚寫出任務限制。
- 每課固定3題理解、2題產出、3題選做；參考答案獨立存於 `lessons/n5/answers/day-NN.md`，只在課文提供連結。各答案說明理由，開放題接受自然的替代說法，不填入學習後紀錄。

## 完成檢查與同步

- 核對正文句數、逐句翻譯、新詞量及主要新文法；確認新文法組內的細項沒有同句堆疊，正文有自然回收。
- 逐句檢查日文讀音、助詞、活用、搭配、指涉及難度；不確定的語言事實需查可靠來源或改用可確認的表達，不能只靠格式檢查宣布日文正確。
- 核對每題可回答、每個答案有依據；確認第十區仍保留給實際學習。
- 在文法與單字索引記錄實際出現的課程連結。必要時拆分文法群組；標明正文、解析或練習中的出現位置，未實現的安排仍保留「預定」。
- 若調整教學順序，同步藍圖與索引。更新教材編寫狀態時，不勾選使用者的學習進度。
- 檢查 Markdown 連結及 `git diff --check`；回報產出、實際完成的檢查與未解決項目，附英文 Conventional Commit 建議。

## 全套產出與覆蓋

使用者要求整套教材時一次完成30篇與對應答案，仍依課次檢查先備。採成人生活情境、固定人物、每篇可獨讀；每課漢字詞首次標音。Day 01沒有舊知識，之後逐步提高回收比例，不能把尚未教的東西說成已學。

先核對[覆蓋表](../../curriculum/n5-coverage.md)。主要句型要有正文實例與解析，口語縮約、同義變體另標辨識，不以形式相近便算全部已教。以重要句型初教後至少三個不同後課重現為目標；實際不足時列出差額、具體練習與回收時點，不假報達標。詞彙以基本形去重，區分正文詞、解析／練習詞及回收詞。

批次完成後跑全套結構與連結檢查，再檢查語言、翻譯、跨句資訊和人物一致性。工具只確認格式或字面出現，不保證自然度或習得效果。不得以補進大量新詞來硬湊正文句數。
