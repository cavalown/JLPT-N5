# N5 學習檢討

## 找到上下文

先讀 [AGENTS.md](../../AGENTS.md)，再讀實際來源課程、題目、使用者原答與相關既有訂正；需要安排後續複習時才讀[藍圖](../../curriculum/n5-roadmap.md)、[易錯點](../../reviews/mistakes.md)和[週複習](../../reviews/weekly-review.md)。

來源不明但能解釋句子時，先解釋可確定部分；要寫回特定課程卻無法確認時，詢問課次或題號，不猜測來源。使用者要求只口頭討論或不要寫檔時依其要求。

## 先判斷問題性質

- **提問或不確定**：釐清意思，不自行認定是錯誤。
- **實際作答**：分清資訊理解、助詞／活用、詞彙搭配及語境自然度；正確的替代表達也算成立。
- **教材有誤或題意模糊**：承認教材問題，修正正文、翻譯或題目及相關索引；保留學習者原答，不將教材問題登記為其錯誤。
- **週複習**：根據實際學過的課文和紀錄出題；沒有作答時只建立待完成任務，不生成成績或熟練度。

## 解答順序

先指出可保留的理解，給一個提示讓使用者再試；仍卡住才給保留原意的最小修正與原因。若使用者直接問原因，直接解說。每個卡點先準備2～3個不同情境的補強題，一次給一題，依回答調整；看過答案後的重答與獨立完成新題分開判斷。

規則、常見傾向、語氣差異與例外要分清楚。「更自然」不直接等於「原句文法錯誤」。若多種解讀取決於語境，說明成立條件。對不確定的語言事實查可靠來源，仍無法確認則標記待確認，不編造定論。

## 寫回與追蹤

只有使用者說「整理」後，才在來源課程的「學習後問題與訂正」追加紀錄，沿用[問題模板](../../templates/question-template.md)的資訊概念；以以下欄位保留最小完整上下文：

- 日期、課次與句號／題號。
- 原句、使用者原答或原問題（原文保留，未提供就不代填）。
- 判斷、建議修正與原因；對比例句按需提供。
- 再練習題、使用者再答與目前狀態；未作答就留待作答。

同一問題有後續回覆時在原紀錄追加，不覆蓋歷次答案。可用 `day-NN-q01` 等穩定HTML錨點連結該紀錄，避免多個同名標題的連結歧義。

只有跨課共通問題才同步到 [文法問題](../../questions/grammar.md)、[單字問題](../../questions/vocabulary.md)或[句子分析](../../questions/sentence-notes.md)，以摘要與來源連結為主，不複製整篇解答。依既有表格填寫，必要的詳細分析保留在來源課程。

實際反覆發生或值得追蹤的錯誤才寫入易錯點；附來源連結及具體後續課次或複習任務。單次值得追蹤的錯誤可記錄，但不要稱為「常犯」。已有同項則追加觀察，避免重複列。

先提出週複習或後課回收建議，待「整理」才寫入；修改已完成教材前先討論。先安排在週複習或適合的課次；若需改藍圖，同步相關配置。不要為單次答錯大幅重寫整套課程。狀態區分「待作答／需提示／待重學／本次可獨立完成」；只有實際回覆能支持狀態變更，一次答對不代表永久掌握。

## 交付檢查

核對原答未被覆寫、訂正與題目對應、教材錯誤未歸咎學習者、複習狀態有證據、來源連結可用。寫檔後執行 `git diff --check`，簡述結論與更新位置，附英文 Conventional Commit 建議；純問答未改檔時不用提供 commit message。

只記錄疑問、錯答、猜對或需提示項目及再練習結果；不逐題複製全部正確答案。提出是否先補強再前進的建議，由使用者決定，不自行鎖住進度。
