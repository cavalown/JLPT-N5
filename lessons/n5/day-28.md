## 日文正文

1. <a id="s01"></a> 旅行（りょこう）の後（あと）で、三人（さんにん）は次（つぎ）の休み（やすみ）の相談（そうだん）をします。
2. <a id="s02"></a> ゆき：日曜日（にちようび）に、わたしの家（いえ）で料理（りょうり）を作りません（つくりません）か。
3. <a id="s03"></a> リン：はい、何時（なんじ）に行きます（いきます）か。
4. <a id="s04"></a> ゆき：十一時（じゅういちじ）に来て（きて）ください。
5. <a id="s05"></a> 田中（たなか）：野菜（やさい）はもう買って（かって）ありますか。
6. <a id="s06"></a> ゆき：いいえ、まだ買っていません。
7. <a id="s07"></a> リン：わたしが買う野菜を紙（かみ）に書いて（かいて）ください。
8. <a id="s08"></a> ゆき：ありがとうございます、三人なので、少し（すこし）だけでいいです。
9. <a id="s09"></a> 田中：わたしは鍋（なべ）を持って（もって）行くつもりです。
10. <a id="s10"></a> ゆき：鍋はありますから、持って来なくてもいいですよ。
11. <a id="s11"></a> リン：日曜日も楽しい（たのしい）一日（いちにち）になるでしょう。
12. <a id="s12"></a> 田中：わたしもゆきさんと料理を作ったことがあります。

## 繁體中文翻譯

1. 旅行後，三人商量下一次休假。
2. ゆき：星期日要不要在我家一起做菜？
3. リン：好，幾點去呢？
4. ゆき：請十一點來。
5. 田中：蔬菜已經買好備著了嗎？
6. ゆき：還沒買。
7. リン：請把要由我買的蔬菜寫在紙上。
8. ゆき：謝謝，因為只有三個人，少量就可以。
9. 田中：我打算帶鍋子去。
10. ゆき：我有鍋子，不用帶來喔。
11. リン：星期日也會是開心的一天吧。
12. 田中：我也曾和ゆき一起做過菜。

## 核心語塊

- まだ買って（かって）いません
- 持って（もって）来なくても（こなくても）いいです
- 楽しい（たのしい）一日（いちにち）になるでしょう

## 新文法解析

<a id="g-integration28"></a>

### 1. 整合：邀請、請求、準備狀態與推測

本課不加主要新文法。先找聚會時間與地點，再區分「已有／未買／不必帶」。第7句先找中心名詞野菜，再理解わたしが買う。

- 正文依據：第2、4、5、6、7、8、9、10、11句。
- 本文例句：ゆき：日曜日（にちようび）に、わたしの家（いえ）で料理（りょうり）を作りません（つくりません）か。

## 舊知識回顧

回顧Day 08、10、16、18、20、22～24、26～27：邀請、選擇、原因、計畫、準備與背景。找出每個人的任務，不把原先打算誤當最後決定。

## 理解題

1. 聚會時間與地點是什麼？
2. 蔬菜買好了嗎？接下來由誰買？
3. 田中需要帶鍋子嗎？為什麼？

## 造句／改寫練習

4. 寫一句答應邀請，再請對方告訴你要買什麼，可分兩句。
5. 用三句回覆：十一點去、會買蔬菜、不帶鍋子。

### 選做題

6. 把「野菜を買います」改為已買好備著。
7. 用ので說因為三個人只買少量。
8. 用でしょう推測下次聚會很開心。
