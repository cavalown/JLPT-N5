# Day 04｜附近有什麼

## 本課目標

- 情境任務：詢問住處附近的場所與人物位置。
- 新文法：ここ／そこ／あそこ／どこ；場所に～があります／います；～は場所にあります／います。
- 本課詞表：10項首次列入、1項回收；僅供本課重點學習，非全文所有生詞統計。
- 理解題可用繁中回答；產出題使用日文。先保存原答，再開啟答案。

## 日文正文

1. <a id="s01"></a> リン：ここはどこですか。
2. <a id="s02"></a> ゆき：ここは駅（えき）の前（まえ）です。
3. <a id="s03"></a> ゆき：あそこにスーパーがあります。
4. <a id="s04"></a> リン：銀行（ぎんこう）もありますか。
5. <a id="s05"></a> ゆき：はい、スーパーの隣（となり）にあります。
6. <a id="s06"></a> リン：田中（たなか）さんはどこにいますか。
7. <a id="s07"></a> ゆき：公園（こうえん）にいます。
8. <a id="s08"></a> リン：あそこに犬（いぬ）がいます。
9. <a id="s09"></a> ゆき：田中さんの犬です。
10. <a id="s10"></a> リン：図書館（としょかん）はどこですか。
11. <a id="s11"></a> ゆき：駅の後ろ（うしろ）にあります。

## 繁體中文翻譯

1. リン：這裡是哪裡？
2. ゆき：這裡是車站前面。
3. ゆき：那裡有超市。
4. リン：也有銀行嗎？
5. ゆき：有，在超市旁邊。
6. リン：田中在哪裡？
7. ゆき：在公園。
8. リン：那裡有狗。
9. ゆき：是田中的狗。
10. リン：圖書館在哪裡？
11. ゆき：在車站後面。

## 核心語塊

- ～はどこですか
- ～にあります
- ～にいます

## 新文法解析

<a id="g-place-word"></a>

### 1. ここ／そこ／あそこ／どこ

表示場所，區分這裡、你那裡、那裡、哪裡；與指物的これ系列不同。

- 正文依據：第1、2、3句。
- 本文例句：リン：ここはどこですか。

<a id="g-exist"></a>

### 2. 場所に～があります／います

に標存在場所，が標存在者。一般物品與設施用あります，人和動物用います。銀行もありますか以も取代が，表示也有。

- 正文依據：第3、4、8句。
- 本文例句：ゆき：あそこにスーパーがあります。

<a id="g-location"></a>

### 3. ～は場所にあります／います

已知要找的對象用は作話題，再提供位置；第5、7、11句省略了已知對象。位置常用「名詞の前／隣／後ろ」。

- 正文依據：第5、6、7、11句。
- 本文例句：ゆき：はい、スーパーの隣（となり）にあります。

## 舊知識回顧

回顧Day 01～03：の、も、指示遠近。あります與います本課先認現在肯定，其他ます變化於Day 06接續。

## 理解題

1. 銀行在哪裡？
2. 田中在哪裡？
3. 圖書館在車站前面嗎？請找證據。

## 造句／改寫練習

4. 用日文說公園裡有狗。
5. 把「スーパーがあります」加上場所「駅の前」。

### 選做題

6. 填空「図書館は駅の後ろに（　）」。
7. 把「田中さんは公園にいます」改成詢問位置。
8. 畫出車站、圖書館、超市與銀行的相對位置，只標正文可確定的資訊。
