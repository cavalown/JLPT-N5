## 日文正文

1. <a id="s01"></a> マンションの入口（いりぐち）です。
2. <a id="s02"></a> 田中（たなか）：これはだれの傘（かさ）ですか。
3. <a id="s03"></a> リン：それはわたしの傘です。
4. <a id="s04"></a> ゆき：このかばんもリンさんのですか。
5. <a id="s05"></a> リン：いいえ、そのかばんはわたしのではありません。
6. <a id="s06"></a> 田中：あれは山田（やまだ）さんのかばんです。
7. <a id="s07"></a> ゆき：どれですか。
8. <a id="s08"></a> 田中：あのかばんです。
9. <a id="s09"></a> リン：この本（ほん）はゆきさんのですか。
10. <a id="s10"></a> ゆき：はい、それはわたしの日本語（にほんご）の本です。
11. <a id="s11"></a> ゆき：ありがとうございます。

## 繁體中文翻譯

1. 這是公寓入口。
2. 田中：這是誰的傘？
3. リン：那是我的傘。
4. ゆき：這個包包也是リン的嗎？
5. リン：不，那個包包不是我的。
6. 田中：那個是山田的包包。
7. ゆき：是哪一個？
8. 田中：是那個包包。
9. リン：這本書是ゆき的嗎？
10. ゆき：是的，那是我的日文書。
11. ゆき：謝謝你。

## 核心語塊

- これはだれの～ですか
- それはわたしのです
- ありがとうございます

## 新文法解析

<a id="g-demonstrative"></a>

### 1. これ／それ／あれ／どれ

可獨立代替物品名詞；本課按說話者近、聽話者近、雙方遠處區分。實際對話也可指先前提過的內容。

- 正文依據：第2、3、6、7句。
- 本文例句：田中（たなか）：これはだれの傘（かさ）ですか。

<a id="g-determiner"></a>

### 2. この／その／あの／どの＋名詞

這組後面必須接名詞；問「哪把傘」是どの傘，不能只說どのですか。

- 正文依據：第4、5、8、9句。
- 本文例句：ゆき：このかばんもリンさんのですか。

<a id="g-nominal-no"></a>

### 3. 名詞の（省略已知物品）

かばん或本已明確，可用リンさんの表示「リン的那個」。這是所有關係的の，後面省略已知名詞。

- 正文依據：第4、5、9句。
- 本文例句：ゆき：このかばんもリンさんのですか。

## 舊知識回顧

回顧Day 01～02：だれ、の、否定與も。ありがとうございます為固定道謝。人物指向隨說話者改變，不能把それ永遠理解為某個固定位置。

## 理解題

1. 雨傘是誰的？
2. 山田的物品是什麼？
3. ゆき為何在最後道謝？

## 造句／改寫練習

4. 將「これ／傘」改成「這把傘」的詞組。
5. 用完整否定句說「那個包包不是我的」。

### 選做題

7. 「それはわたしのです」省略了什麼？請依第3句回答。
8. 你拿著書，問是不是ゆき的，寫一句。
