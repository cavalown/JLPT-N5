## 日文正文

1. <a id="s01"></a> ゆき：週末（しゅうまつ）は海（うみ）か山（やま）へ行きません（いきません）か。
2. <a id="s02"></a> リン：海と山と、どちらが近い（ちかい）ですか。
3. <a id="s03"></a> ゆき：海のほうが近いです。
4. <a id="s04"></a> 田中（たなか）：山は海より遠い（とおい）です。
5. <a id="s05"></a> リン：バスと電車（でんしゃ）と、どちらが安い（やすい）ですか。
6. <a id="s06"></a> 田中：バスのほうが安いです。
7. <a id="s07"></a> ゆき：でも、電車のほうが速い（はやい）です。
8. <a id="s08"></a> リン：この三つ（みっつ）の町（まち）の中（なか）で、どこがいちばん静か（しずか）ですか。
9. <a id="s09"></a> 田中：海の近く（ちかく）の町です。
10. <a id="s10"></a> リン：では、海にしましょう。
11. <a id="s11"></a> ゆき：いいですね。

## 繁體中文翻譯

1. ゆき：週末要不要去海邊或山裡？
2. リン：海邊和山裡，哪個比較近？
3. ゆき：海邊比較近。
4. 田中：山裡比海邊遠。
5. リン：巴士和電車，哪個便宜？
6. 田中：巴士比較便宜。
7. ゆき：不過電車比較快。
8. リン：這三個城鎮中，哪裡最安靜？
9. 田中：海邊附近的城鎮。
10. リン：那麼就選海邊吧。
11. ゆき：好啊。

## 核心語塊

- どちらが近い（ちかい）ですか
- ～のほうが安い（やすい）です
- ～の中（なか）でいちばん

## 新文法解析

<a id="g-compare"></a>

### 1. AはBより～／Aのほうが～

より標比較基準，ほう指其中一方。山は海より遠い說山較遠；海より山のほうが遠い也是同一比較。

- 正文依據：第3、4、6、7句。
- 本文例句：ゆき：海のほうが近いです。

<a id="g-compare-question"></a>

### 2. AとBとどちらが～

比較兩方常用どちら；依問題回答～のほうが…。と在此列出兩個比較對象。

- 正文依據：第2、5句。
- 本文例句：リン：海と山と、どちらが近い（ちかい）ですか。

<a id="g-superlative"></a>

### 3. 範圍の中で～がいちばん

先限定比較範圍，再選最符合性質者。比較場所問どこ，人物問だれ；並非任何比較都用どちら。

- 正文依據：第8、9句。
- 本文例句：リン：この三つ（みっつ）の町（まち）の中（なか）で、どこがいちばん静か（しずか）ですか。

## 舊知識回顧

回顧Day 08、10～11：か的選項、にします、ましょう、形容詞。第10句にしましょう是にします接提議形，表示一起選定。

## 理解題

1. 海和山哪個更近？
2. 巴士與電車各有什麼優點？
3. 大家最後選哪裡？文中有哪兩項支持這選擇？

## 造句／改寫練習

4. 用より說山比海遠。
5. 詢問巴士與電車哪個快。

### 選做題

6. 依正文用ほうが回答上一題。
7. 用「この町／いちばん」說這個城鎮最安靜。
8. 以便宜為優先，用兩句選交通方式並比較。
