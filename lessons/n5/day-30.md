## 日文正文

1. <a id="s01"></a> 日本（にほん）の生活（せいかつ）は、もう一か月（いっかげつ）です。
2. <a id="s02"></a> ゆき：日本語（にほんご）の勉強はどうですか。
3. <a id="s03"></a> リン：前（まえ）は、日本語があまりわかりませんでした。
4. <a id="s04"></a> 今（いま）は店（みせ）で買いたい（かいたい）物（もの）を言う（いう）ことができます。
5. <a id="s05"></a> ゆき：この一か月はどうでしたか。
6. <a id="s06"></a> リン：海（うみ）へ行った（いった）り、一緒に（いっしょに）料理（りょうり）を作った（つくった）りして、楽しかった（たのしかった）です。
7. <a id="s07"></a> 田中（たなか）：また海へ行きたいですか。
8. <a id="s08"></a> リン：はい、でも、その前に日本語をもっと勉強する（べんきょうする）つもりです。
9. <a id="s09"></a> ゆき：毎日（まいにち）たくさん勉強しなくてもいいですよ。
10. <a id="s10"></a> リン：まだ知らない（しらない）言葉（ことば）がたくさんあるんです。
11. <a id="s11"></a> 田中：話す（はなす）のが上手（じょうず）になるでしょう。
12. <a id="s12"></a> リン：また、母（はは）や友達（ともだち）に花（はな）をあげたいです。

## 繁體中文翻譯

1. 在日本的生活已經一個月了。
2. ゆき：日文學習怎麼樣？
3. リン：以前不太懂日文。
4. 現在能在店裡說出想買的東西。
5. ゆき：這一個月怎麼樣？
6. リン：去海邊、一起做菜等，很開心。
7. 田中：還想去海邊嗎？
8. リン：想，不過在那之前，我打算再多學日文。
9. ゆき：不必每天都學很多喔。
10. リン：因為還有很多不認識的詞。
11. 田中：說話會進步吧。
12. リン：我還想再送花給媽媽、朋友等人。

## 新文法解析

<a id="g-integration30"></a>

### 1. 整合：過去與現在、經驗、能力、計畫與變化

本課不加主要新文法。會讀或寫過教材不等於永久熟練；故事角色的進步是劇情，不代表使用者已有同等能力。第11句是鼓勵性的推測。

- 正文依據：第1、3、4、6、8、9、10、11句。
- 本文例句：日本（にほん）の生活（せいかつ）は、もう一か月（いっかげつ）です。
