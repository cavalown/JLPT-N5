## 日文正文

1. <a id="s01"></a> リンはよく図書館（としょかん）へ行きます（いきます）。
2. <a id="s02"></a> 一週間（いっしゅうかん）に二回（にかい）、本（ほん）を借ります（かります）。
3. <a id="s03"></a> ゆき：いつも日本語（にほんご）の本ですか。

5. <a id="s05"></a> ゆき：わたしは時々（ときどき）雑誌（ざっし）を読みます（よみます）。
6. <a id="s06"></a> リン：わたしは雑誌をあまり読みません。
7. <a id="s07"></a> ゆき：この図書館は静か（しずか）ですね。
8. <a id="s08"></a> リン：ええ、ここでは全然（ぜんぜん）話しません（はなしません）。
9. <a id="s09"></a> 図書館の外（そと）に田中（たなか）さんがいます。
10. <a id="s10"></a> 田中：三十分（さんじゅっぷん）ぐらい公園（こうえん）を歩きます（あるきます）。
11. <a id="s11"></a> リン：わたしも一緒に（いっしょに）歩きます。

## 繁體中文翻譯

1. リン經常去圖書館。
2. 一週借兩次書。
3. ゆき：總是日文書嗎？
4. リン：是的，今天借兩本。
5. ゆき：我有時讀雜誌。
6. リン：我不太讀雜誌。
7. ゆき：這間圖書館很安靜呢。
8. リン：對，在這裡我完全不說話。
9. 田中在圖書館外面。
10. 田中：我要在公園走大約三十分鐘。
11. リン：我也一起走。

## 核心語塊

- 一週間（いっしゅうかん）に二回（にかい）
- 本（ほん）を二冊（にさつ）借ります（かります）
- 三十分（さんじゅっぷん）ぐらい歩きます（あるきます）

## 新文法解析

<a id="g-frequency"></a>

### 1. 頻率副詞與期間に～回

いつも、よく、時々描述頻率；本課あまり／全然配否定。期間に回數表示一定期間發生幾次，不是第幾次。

- 正文依據：第1、2、3、5、6、8句。
- 本文例句：リンはよく図書館（としょかん）へ行きます（いきます）。

<a id="g-counters"></a>

### 2. 冊・枚・本／期間ぐらい

書用冊，薄片用枚，細長物用本：一冊いっさつ、一枚いちまい、一本いっぽん。期間＋ぐらい表示約多久，區別三時的時點。

- 正文依據：第4、10句。
- 本文例句：リン：はい、今日（きょう）は二冊（にさつ）借ります。

<a id="g-path"></a>

### 3. 場所を＋移動動詞

公園を歩く表示走動經過的範圍；同一を不只標受詞。說離開家可用家を出ます，後課會回收。

- 正文依據：第10、11句。
- 本文例句：田中：三十分（さんじゅっぷん）ぐらい公園（こうえん）を歩きます（あるきます）。

## 舊知識回顧

回顧Day 06～07、09～10、13：時間、交通、數量、好き。第8句では是場所で加對比は，不是名詞否定ではありません的整體結構。

1. リン一週借幾次書？
2. ゆき讀雜誌的頻率如何？
3. 田中打算在哪裡走多久？

## 造句／改寫練習

4. 用「一週間／三回」說一週讀三次書。
5. 用あまり否定自己常喝咖啡。

7. 說在公園走大約十分鐘（じゅっぷん）。
