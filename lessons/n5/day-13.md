## 日文正文

1. <a id="s01"></a> 今日（きょう）は公園（こうえん）でゆきと話します（はなします）。
2. <a id="s02"></a> リン：ゆきさんは音楽（おんがく）が好き（すき）ですか。
3. <a id="s03"></a> ゆき：はい、歌（うた）も好きです。
4. <a id="s04"></a> リン：わたしは料理（りょうり）が好きです。
5. <a id="s05"></a> ゆき：田中（たなか）さんも料理が上手（じょうず）です。
6. <a id="s06"></a> リン：わたしはまだ上手ではありません。
7. <a id="s07"></a> ゆき：どんな料理が好きですか。
8. <a id="s08"></a> リン：魚（さかな）の料理が好きです。
9. <a id="s09"></a> ゆき：わたしは魚が少し（すこし）苦手（にがて）です。
10. <a id="s10"></a> リン：肉（にく）はどうですか。
11. <a id="s11"></a> ゆき：肉は好きです。

## 繁體中文翻譯

1. 今天在公園和ゆき聊天。
2. リン：ゆき喜歡音樂嗎？
3. ゆき：喜歡，也喜歡歌曲。
4. リン：我喜歡料理。
5. ゆき：田中也很擅長做菜。
6. リン：我還不擅長。
7. ゆき：喜歡什麼樣的料理？
8. リン：我喜歡魚料理。
9. ゆき：我有點不太能接受魚。
10. リン：肉怎麼樣？
11. ゆき：肉的話我喜歡。

## 核心語塊

- ～が好き（すき）です
- まだ上手（じょうず）ではありません
- 少し（すこし）苦手（にがて）です

## 新文法解析

<a id="g-preference"></a>

### 1. 名詞が好き／嫌い

喜好對象常用が；嫌い表示討厭，語氣較強。第11句肉は與先前的魚作對比，不能說喜好對象永遠只能用が。 理解對象也常接が：日本語がわかります；否定日本語がわかりません。

- 正文依據：第2、3、4、8、11句。
- 本文例句：リン：ゆきさんは音楽（おんがく）が好き（すき）ですか。

<a id="g-skill"></a>

### 2. 名詞が上手／下手／苦手

上手稱讚技巧，下手指技巧不好；苦手可指不擅長或不喜歡。自述通常用得意或まだ上手ではありません等較合情境說法，不隨意自誇上手。

- 正文依據：第5、6、9句。
- 本文例句：ゆき：田中（たなか）さんも料理が上手（じょうず）です。

<a id="g-still"></a>

### 3. まだ＋肯定／否定

まだ表示狀態還持續；まだ上手ではありません是尚未擅長。與已經的もう在Day 22對照。

- 正文依據：第6句。
- 本文例句：リン：わたしはまだ上手ではありません。

## 舊知識回顧

回顧Day 02、11～12：も、は的對比、な形容詞否定、程度。少し苦手是較緩和的說法，不等同毫無能力。

## 理解題

1. ゆき喜歡哪些與音樂有關的事？
2. 誰被稱讚擅長料理？
3. 下次一起吃飯，選魚還是肉比較符合ゆき的偏好？

## 造句／改寫練習

4. 用が好き說一項自己的喜好，可使用本課名詞。
5. 將「料理が上手です」改為還不擅長。

### 選做題

6. 用どんな問對方喜歡哪類料理。
7. 把「音楽が好きです」改為不喜歡（非強烈討厭）。
8. 用兩句說喜歡和不太擅長的事。
