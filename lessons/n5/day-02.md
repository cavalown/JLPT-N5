## 日文正文

1. <a id="s01"></a> ゆき：田中（たなか）さんは先生（せんせい）ですか。
2. <a id="s02"></a> 田中：いいえ、先生ではありません。
3. <a id="s03"></a> 田中：このマンションの管理人（かんりにん）です。
4. <a id="s04"></a> ゆき：わたしは会社員（かいしゃいん）です。
5. <a id="s05"></a> リン：わたしも会社員です。
6. <a id="s06"></a> 田中：リンさんのご家族（かぞく）は台湾（たいわん）ですか。
7. <a id="s07"></a> リン：はい、父（ちち）も母（はは）も台湾です。
8. <a id="s08"></a> ゆき：あの人（ひと）はだれですか。
9. <a id="s09"></a> 田中：わたしの友達（ともだち）です。
10. <a id="s10"></a> リン：お名前（なまえ）は何（なん）ですか。
11. <a id="s11"></a> 田中：山田（やまだ）さんです。

## 繁體中文翻譯

1. ゆき：田中先生是老師嗎？
2. 田中：不，我不是老師。
3. 田中：我是這棟公寓的管理員。
4. ゆき：我是上班族。
5. リン：我也是上班族。
6. 田中：リン，你的家人在台灣嗎？
7. リン：是的，爸爸和媽媽都在台灣。
8. ゆき：那個人是誰？
9. 田中：是我的朋友。
10. リン：名字是什麼呢？
11. 田中：是山田先生。

## 核心語塊

- いいえ、～ではありません
- わたしも～です
- お名前（なまえ）は何（なん）ですか

## 新文法解析

<a id="g-negative-noun"></a>

### 1. 名詞句否定

名詞＋ではありません否定身分；較口語為じゃありません。普通體ではない／じゃない在朋友間可見，但本課先練禮貌體。不要在名詞後接ません。

- 正文依據：第1、2句。
- 本文例句：ゆき：田中（たなか）さんは先生（せんせい）ですか。

<a id="g-also"></a>

### 2. ～も／AもBも

も表示也，可取代本來的は；AもBも表示A與B都如此。不寫わたしはも。

- 正文依據：第4、5、7句。
- 本文例句：ゆき：わたしは会社員（かいしゃいん）です。

<a id="g-wh-person"></a>

### 3. だれ／何ですか

人用だれ，事物或名字可用何ですか，本課何讀なん。對他人直接問だれですか可能生硬，先用お名前詢問名字。

- 正文依據：第8、10、11句。
- 本文例句：ゆき：あの人（ひと）はだれですか。

## 舊知識回顧

回顧Day 01：は、です、か、の。第3句この、第8句あの先作指示語塊，Day 03正式區分。ご家族的ご與お名前的お都可使稱呼較有禮貌，但不能任意互換或加在每個名詞前。

## 理解題

1. 田中是老師嗎？
2. リン和ゆき有什麼共同點？
3. 山田是誰的朋友？

## 造句／改寫練習

4. 用禮貌體把「先生です」改為否定。
5. 用も說「我也是上班族」。

### 選做題

6. 填空「あの人は（　）ですか」，詢問人物。
7. 把「父は台湾です。母は台湾です」合成一句。
8. 更正「わたしはも会社員です」。
