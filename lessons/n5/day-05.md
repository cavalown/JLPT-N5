## 日文正文

1. <a id="s01"></a> リンの部屋（へや）にゆきがいます。
2. <a id="s02"></a> ゆき：机（つくえ）の上（うえ）に本（ほん）とノートがあります。
3. <a id="s03"></a> リン：本は日本語（にほんご）の本です。
4. <a id="s04"></a> ゆき：かばんの中（なか）に何（なん）がありますか。
5. <a id="s05"></a> リン：財布（さいふ）や鍵（かぎ）があります。
6. <a id="s06"></a> ゆき：その鍵はどこですか。
7. <a id="s07"></a> リン：あれ、かばんの中ではありません。
8. <a id="s08"></a> ゆき：椅子（いす）の下（した）に箱（はこ）があります。
9. <a id="s09"></a> リン：あの箱は母（はは）のです。
10. <a id="s10"></a> ゆき：鍵は箱と椅子の間（あいだ）にあります。
11. <a id="s11"></a> リン：あ、ありがとうございます。

## 繁體中文翻譯

1. ゆき在リン的房間。
2. ゆき：桌上有書和筆記本。
3. リン：書是日文書。
4. ゆき：包包裡有什麼？
5. リン：有錢包、鑰匙等東西。
6. ゆき：那把鑰匙在哪裡？
7. リン：咦，不是在包包裡。
8. ゆき：椅子下有盒子。
9. リン：那個盒子是媽媽的。
10. ゆき：鑰匙在盒子與椅子之間。
11. リン：啊，謝謝你。

## 核心語塊

- 机（つくえ）の上（うえ）に
- かばんの中（なか）に
- ～と～の間（あいだ）に

## 新文法解析

<a id="g-relative"></a>

### 1. 名詞の位置／AとBの間

位置以參照物為中心：机の上、椅子の下；兩個參照物用AとBの間。位置作存在場所時接に。

- 正文依據：第2、4、8、10句。
- 本文例句：ゆき：机（つくえ）の上（うえ）に本（ほん）とノートがあります。

<a id="g-list-to"></a>

### 2. 名詞と名詞

と連接明列的項目；不表示這個場所不可能還有其他物品，但說話者將本次列舉當作完整列項。

- 正文依據：第2、10句。
- 本文例句：ゆき：机（つくえ）の上（うえ）に本（ほん）とノートがあります。

<a id="g-list-ya"></a>

### 3. 名詞や名詞

や表示舉例列舉，暗示還可能有其他項目；常與など搭配成AやBなど，但第5句不用など也成立。

- 正文依據：第5句。
- 本文例句：リン：財布（さいふ）や鍵（かぎ）があります。

## 舊知識回顧

回顧Day 03～04：物主の、存在句、位置問句。第5句是リン起初以為的位置，後來第7句自我更正，不把人物猜測當作最後事實。あれ是驚訝語氣，與指物的あれ由語境區分。

## 理解題

1. ゆき在哪裡？
2. 桌上明列了哪兩樣物品？
3. 鑰匙最後在哪裡？

## 造句／改寫練習

4. 用「机／上／本」寫存在句。
5. 列舉包包裡有錢包、書等物品，保留還有其他東西的意思。

### 選做題

6. 問鑰匙在哪裡。
7. 把「箱と椅子の間」翻成中文。
8. 用兩句描述你房間裡的物品，可虛構。
