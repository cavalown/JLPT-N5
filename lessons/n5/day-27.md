## 日文正文

1. <a id="s01"></a> 昼ご飯（ひるごはん）の後（あと）で、リンは店（みせ）へ行きました（いきました）。
2. <a id="s02"></a> ゆき：リンさんが買った（かった）物（もの）は何（なん）ですか。
3. <a id="s03"></a> リン：母（はは）にあげる花（はな）です。
4. <a id="s04"></a> ゆき：母の日（ははのひ）のプレゼントですか。
5. <a id="s05"></a> リン：いいえ、母の誕生日（たんじょうび）なんです。
6. <a id="s06"></a> ゆき：それで、花を買ったんですね。
7. <a id="s07"></a> リン：田中（たなか）さんはどの人（ひと）ですか。
8. <a id="s08"></a> ゆき：白い（しろい）帽子（ぼうし）をかぶっている人です。
9. <a id="s09"></a> リン：あ、明日（あした）も晴れる（はれる）でしょうか。
10. <a id="s10"></a> 田中：たぶん、晴れるでしょう。
11. <a id="s11"></a> リン：いい一日（いちにち）だなあ。
12. <a id="s12"></a> 田中：この町（まち）へ来た（きた）ことがありますから、店も知って（しって）います。

## 繁體中文翻譯

1. 午餐後リン去了店裡。
2. ゆき：リン買的東西是什麼？
3. リン：是要給媽媽的花。
4. ゆき：是母親節禮物嗎？
5. リン：不是，是因為媽媽生日。
6. ゆき：所以才買花啊。
7. リン：哪位是田中？
8. ゆき：戴白帽子的那位。
9. リン：啊，明天也會放晴嗎？
10. 田中：大概會放晴吧。
11. リン：真是美好的一天啊。
12. 田中：因為來過這個城鎮，所以也知道這裡的店。

## 核心語塊

- わたしが買った（かった）物（もの）
- 誕生日（たんじょうび）なんです
- 晴れる（はれる）でしょう

## 新文法解析

<a id="g-relative-clause"></a>

### 1. 普通形＋名詞

買った物是買過的東西，あげる花是要送的花，かぶっている人以狀態辨識人。修飾句直接放名詞前，不加の；先找最後的中心名詞再理解前面的資訊。

- 正文依據：第2、3、8句。
- 本文例句：ゆき：リンさんが買った（かった）物（もの）は何（なん）ですか。

<a id="g-explanation"></a>

### 2. ～んです／～のです

用已知情境補充背景；普通形＋んです，名詞與な形容詞現在肯定為なんです。誕生日なんです較口語，誕生日なのです較書面。不能把每個です都任意替換而不改語氣。

- 正文依據：第5、6句。
- 本文例句：リン：いいえ、母の誕生日（たんじょうび）なんです。

<a id="g-speculation"></a>

### 3. でしょう／だろう／だ・なあ

普通形＋でしょう表推測，名詞與な形容詞不加だ再接でしょう；だろう較普通體。名詞斷定普通體是だ，いい一日だなあ是自言自語感嘆。なあ與對人確認的ね功能不完全相同。

- 正文依據：第9、10、11句。
- 本文例句：リン：あ、明日（あした）も晴れる（はれる）でしょうか。

## 舊知識回顧

回顧Day 03、17～18、24～26：指示、人際授受、穿戴持續狀態、た形與時間。第3句是準備送的花，尚未送到；前篇買花的心願在旅途中延續。日語可把過去與未來動作都拿來修飾名詞。

1. 花是要送給誰的？
2. ゆき先猜了哪個送花理由？真正理由是什麼？
3. ゆき用什麼資訊辨識田中？

## 造句／改寫練習

4. 把「リンさんが買いました／本」組成「リン買的書」。
5. 用んです說明今天是休假。

### 選做題

6. 用でしょう推測明天會晴。
7. 將「晴れるでしょう」改成較普通體的推測。
8. 用兩句介紹一件買過的物品及原因。
