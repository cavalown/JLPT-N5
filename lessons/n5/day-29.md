## 日文正文

1. <a id="s01"></a> 日曜日（にちようび）、リンはゆきの家（いえ）へ行きました（いきました）。
2. <a id="s02"></a> 買った（かった）野菜（やさい）はかばんの中（なか）にあります。
3. <a id="s03"></a> 田中（たなか）：わたしはもう手（て）を洗いました（あらいました）。
4. <a id="s04"></a> ゆき：リンさんも手を洗ってから、料理（りょうり）を作りましょう（つくりましょう）。
5. <a id="s05"></a> リン：この野菜は全部（ぜんぶ）使って（つかって）もいいですか。
6. <a id="s06"></a> ゆき：ええ、でも、この肉（にく）は使わないでください。
7. <a id="s07"></a> ゆき：明日（あした）のお弁当（べんとう）の肉なんです。
8. <a id="s08"></a> リン：では、今日（きょう）は野菜のスープにしましょう。
9. <a id="s09"></a> 田中：ゆっくり作ったほうがいいですよ。
10. <a id="s10"></a> 三人（さんにん）は料理を作ったり、旅行（りょこう）の話（はなし）をしたりしました。
11. <a id="s11"></a> 前（まえ）のスープより、今日のスープのほうがおいしいでしょう。
12. <a id="s12"></a> リン：次（つぎ）は、スープの作り方の本（ほん）がほしいです。

## 繁體中文翻譯

1. 星期日，リン去了ゆき家。
2. 買好的蔬菜在包包裡。
3. 田中：我已經洗手了。
4. ゆき：リン也洗完手後，再一起做菜吧。
5. リン：這些蔬菜可以全部用嗎？
6. ゆき：可以，但請不要用這些肉。
7. ゆき：那是明天便當要用的肉。
8. リン：那麼今天就做蔬菜湯吧。
9. 田中：慢慢做比較好喔。
10. 三人做菜、聊旅行等。
11. 今天的湯大概比之前的湯更好喝吧。
12. リン：下次我想要一本教人做湯的書。

## 核心語塊

- 使わない（つかわない）でください
- 明日（あした）のお弁当（べんとう）なんです
- ～より～のほうが

## 新文法解析

<a id="g-integration29"></a>

### 1. 整合：辨識物品、先後、許可與背景說明

本課不加主要新文法。區分使ってもいい與使わないでください；第7句說明限制的背景，第11句是推測，不是已確認的客觀評分。

- 正文依據：第2、4、5、6、7、8、9、10、11句。
- 本文例句：買った（かった）野菜（やさい）はかばんの中（なか）にあります。

## 舊知識回顧

回顧Day 05、12、15、20～27：空間、過去、比較、否定請求、てから、許可、た形、背景與推測。料理故事延續Day 21，但不用記得那篇細節也能判斷本課。

## 理解題

1. リン帶來的蔬菜放在哪裡？
2. 為什麼不能用那些肉？
3. 大家最後做什麼料理？由哪個限制改變選擇？

## 造句／改寫練習

4. 用てから寫你洗手後做菜。
5. 寫3～4句當日紀錄，包含帶蔬菜、料理、聊天。

### 選做題

6. 用んです說明這是明天的便當。
7. 將「ゆっくり作ります」改為建議對方慢慢做。
8. 第11句能否證明大家吃過後一致認為今天較好喝？
