1. <a id="s01"></a> リン：はじめまして。
2. <a id="s02"></a> リン：わたしはリンです。
3. <a id="s03"></a> リン：台湾（たいわん）の会社員（かいしゃいん）です。
4. <a id="s04"></a> ゆき：わたしはゆきです。

8. <a id="s08"></a> ゆき：田中（たなか）さんはマンションの管理人（かんりにん）です。
9. <a id="s09"></a> 田中：はじめまして。
10. <a id="s10"></a> 田中：お名前（なまえ）はリンさんですか。
11. <a id="s11"></a> リン：はい、よろしくお願い（おねがい）します。

## 繁體中文翻譯

1. リン：初次見面。
2. リン：我是リン。
3. リン：我是台灣的上班族。
4. ゆき：我是ゆき。
5. ゆき：我是日本人。
6. ゆき：リン小姐／先生，你是櫻花公寓的住戶嗎？
7. リン：是的，沒錯。
8. ゆき：田中先生是公寓管理員。
9. 田中：初次見面。
10. 田中：你的名字是リン嗎？
11. リン：是的，請多指教。

## 核心語塊

- はじめまして
- はい、そうです
- よろしくお願い（おねがい）します

## 新文法解析

<a id="g-topic"></a>

### 1. AはBです

用A當話題，再說A的身分。は讀作わ；です是禮貌句尾，不把は直接等同中文「是」。人物已明確時可省略Aは，如第5句。

- 正文依據：第2、3、4、5句。
- 本文例句：リン：わたしはリンです。

<a id="g-question"></a>

### 2. ～ですか／はい、そうです

か置於句尾表示詢問。肯定身分可答はい、そうです。第10句省略了可由語境理解的「你的」。

- 正文依據：第6、7、10句。
- 本文例句：ゆき：リンさんはさくらマンションの住人（じゅうにん）ですか。

<a id="g-possess"></a>

### 3. 名詞の名詞

後一個名詞是中心，前項限定來源或所屬；台湾の会社員是台灣的上班族。不能用の任意連接所有詞。

- 正文依據：第3、6、8句。
- 本文例句：リン：台湾（たいわん）の会社員（かいしゃいん）です。

## 舊知識回顧

起點課：沒有先前課程；先確認能辨讀假名。はじめまして與よろしくお願いします先整塊理解為初見招呼，不拆解其中動詞。お名前的お是禮貌前綴；さん是稱呼他人的敬稱，不加在自稱後。

## 理解題

1. リン的職業是什麼？
2. 田中與這棟公寓有什麼關係？
3. 哪兩句合起來可確認リン住在櫻花公寓？

## 造句／改寫練習

4. 用「わたしは～です」介紹自己的名字。
5. 把「マンション／管理人」組成一個表示所屬的詞組。

### 選做題

6. 把「ゆきさんは日本人です」改成問句。
7. 用日文肯定回答「リンさんですか」。
8. 寫兩句自我介紹，包含名字與身分，可使用虛構身分。
