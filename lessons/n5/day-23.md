## 日文正文

1. <a id="s01"></a> 旅行（りょこう）の地図（ちず）を借りに（かりに）、図書館（としょかん）へ行きます（いきます）。
2. <a id="s02"></a> リン：この部屋（へや）で写真（しゃしん）を撮って（とって）もいいですか。
3. <a id="s03"></a> 係（かかり）の人（ひと）：いいえ、ここで撮ってはいけません。
4. <a id="s04"></a> ゆき：外（そと）で撮ってもいいですか。
5. <a id="s05"></a> 係の人：はい、外はいいですよ。
6. <a id="s06"></a> リン：この紙（かみ）にも名前（なまえ）を書かなければ（かかなければ）なりませんか。
7. <a id="s07"></a> 係の人：いいえ、それには書かなくてもいいです。
8. <a id="s08"></a> 田中（たなか）：本（ほん）はいつ返します（かえします）か。
9. <a id="s09"></a> 係の人：来週（らいしゅう）の日曜日（にちようび）に返してください。
10. <a id="s10"></a> ゆき：借りた本を忘れて（わすれて）はいけませんね。
11. <a id="s11"></a> リン：はい、かばんに入れて（いれて）から帰ります（かえります）。
12. <a id="s12"></a> リン：では、この地図の本を一冊（いっさつ）だけ借ります。

## 繁體中文翻譯

1. 為了借旅行地圖，大家去圖書館。
2. リン：可以在這個房間拍照嗎？
3. 工作人員：不可以，這裡不能拍照。
4. ゆき：可以在外面拍嗎？
5. 工作人員：可以，外面可以喔。
6. リン：這張紙也必須寫名字嗎？
7. 工作人員：不用，那張不用寫。
8. 田中：書什麼時候還？
9. 工作人員：請在下週日歸還。
10. ゆき：可不能忘記借來的書呢。
11. リン：好，我放進包包後再回去。
12. リン：那麼，我只借這一本地圖書。

## 核心語塊

- 撮って（とって）もいいですか
- 撮って（とって）はいけません
- 書かなくても（かかなくても）いいです

## 新文法解析

<a id="g-permission"></a>

### 1. ～てもいいです

て形＋もいいです表示允許；加か請求許可。肯定可答はい、いいですよ，不必完整重複全部句型。

- 正文依據：第2、4、5句。
- 本文例句：リン：この部屋（へや）で写真（しゃしん）を撮って（とって）もいいですか。

<a id="g-prohibition"></a>

### 2. ～てはいけません

表示規定上的禁止。口語ては→ちゃ、では→じゃ：撮っちゃいけない／ここで飲んじゃいけない。先辨識，不把禁止誤解為能力不會。

- 正文依據：第3、10句。
- 本文例句：係（かかり）の人（ひと）：いいえ、ここで撮ってはいけません。

<a id="g-no-obligation"></a>

### 3. ～なくてもいいです

ない形去い＋くてもいいです表示不必，不是不能。與書かなければなりません（必須寫）及書いてはいけません（禁止寫）對照。

- 正文依據：第7句。
- 本文例句：係の人：いいえ、それには書かなくてもいいです。
