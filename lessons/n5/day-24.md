# Day 24｜出門前的一通電話

## 本課目標

- 情境任務：理解正在做、持續狀態與事先準備好的結果。
- 新文法：～ています：進行／持續狀態；～てあります；家を出る／動詞連接回顧。
- 本課詞表：5項首次列入、3項回收；僅供本課重點學習，非全文所有生詞統計。
- 理解題可用繁中回答；產出題使用日文。先保存原答，再開啟答案。

## 日文正文

1. <a id="s01"></a> ゆき：今（いま）、何（なん）をしていますか。
2. <a id="s02"></a> リン：弁当（べんとう）を作って（つくって）います。
3. <a id="s03"></a> ゆき：田中（たなか）さんはもう駅（えき）にいますよ。
4. <a id="s04"></a> リン：田中さんは駅の近く（ちかく）に住んで（すんで）いますね。
5. <a id="s05"></a> ゆき：はい、わたしたちのマンションです。
6. <a id="s06"></a> リン：駅の新しい（あたらしい）入口（いりぐち）を知って（しって）いますか。
7. <a id="s07"></a> ゆき：いいえ、知りません。
8. <a id="s08"></a> リン：地図（ちず）に入口が書いて（かいて）あります。
9. <a id="s09"></a> ゆき：では、駅で見せて（みせて）ください。
10. <a id="s10"></a> リン：はい、地図はもうかばんに入れて（いれて）あります。
11. <a id="s11"></a> リンは電話（でんわ）を終えて（おえて）、家（いえ）を出ます（でます）。

## 繁體中文翻譯

1. ゆき：現在在做什麼？
2. リン：我正在做便當。
3. ゆき：田中已經在車站了喔。
4. リン：田中住在車站附近呢。
5. ゆき：對，就是我們的公寓。
6. リン：你知道車站的新入口嗎？
7. ゆき：不，我不知道。
8. リン：地圖上已標有入口。
9. ゆき：那麼到車站請給我看。
10. リン：好，地圖已經放進包包備好了。
11. リン結束通話後出門。

## 核心語塊

- 何（なん）をしていますか
- 知って（しって）います／知りません
- 書いて（かいて）あります

## 新文法解析

<a id="g-ongoing"></a>

### 1. ～ています：進行／持續狀態

作っています是現在正在做；住んでいます是居住狀態，不能一律翻成正在。知っています表示知道，否定通常知りません，不用知っていません表達一般不知道。

- 正文依據：第1、2、4句。
- 本文例句：ゆき：今（いま）、何（なん）をしていますか。

<a id="g-prepared"></a>

### 2. ～てあります

他人有意做某動作後留下的狀態：入口が書いてあります。準備好的物品也可用は／を，如地図は入れてあります。與單純動作正在進行的ています不同。

- 正文依據：第8、10句。
- 本文例句：リン：地図（ちず）に入口が書いて（かいて）あります。

<a id="g-leave"></a>

### 3. 家を出る／動詞連接回顧

を可標離開點；電話を終えて、家を出る是先結束通話，再出門。第11句沒有表示正在打電話。

- 正文依據：第11句。
- 本文例句：リンは電話（でんわ）を終えて（おえて）、家（いえ）を出ます（でます）。

## 舊知識回顧

回顧Day 04、14、21～23：存在與動作場所、を的路徑、て形、已完成與請求。第6～7句知道的否定是本課必要例外。

## 理解題

1. リン接電話時在做什麼？
2. ゆき知道新入口嗎？
3. リン如何確保到站能給ゆき看地圖？

## 造句／改寫練習

4. 用ています說自己住在車站附近。
5. 否定回答「新しい入口を知っていますか」。

### 選做題

6. 把「今、弁当を作ります」改為正在做。
7. 說紙上已寫好名字（以名字為主語）。
8. 說地圖放好後才出門。
