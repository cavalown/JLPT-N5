## 日文正文

1. <a id="s01"></a> 昨日（きのう）は雨（あめ）でした。
2. <a id="s02"></a> リンは家（いえ）で昼ご飯（ひるごはん）を食べました（たべました）。
3. <a id="s03"></a> ゆき：昨日は忙しかった（いそがしかった）ですか。
4. <a id="s04"></a> リン：いいえ、忙しくなかったです。
5. <a id="s05"></a> リン：休み（やすみ）でした。
6. <a id="s06"></a> ゆき：昼ご飯はどうでしたか。
7. <a id="s07"></a> リン：スープは温かく（あたたかく）て、おいしかったです。
8. <a id="s08"></a> リン：でも、パンはあまりおいしくなかったです。
9. <a id="s09"></a> ゆき：店（みせ）のパンですか。
10. <a id="s10"></a> リン：はい、昨日の（きのうの）パンは新しくありません（あたらしくありません）でした。
11. <a id="s11"></a> 今日（きょう）はいい天気（てんき）です。

3. ゆき：昨天忙嗎？

5. リン：我放假。
6. ゆき：午餐怎麼樣？
7. リン：湯熱熱的，很好喝。

## 核心語塊

- 昨日（きのう）は雨（あめ）でした
- 忙しくなかった（いそがしくなかった）です
- あまり～くなかったです

## 新文法解析

<a id="g-past-adjective"></a>

### 1. い形容詞過去肯否／くて

忙しい→忙しかったです／忙しくなかったです。否定禮貌另一式為忙しくありませんでした。いい→よかったです／よくなかったです。連接描述把い換くて，如温かくて；本課是並列特徵。

- 正文依據：第3、4、7、8、10句。
- 本文例句：ゆき：昨日は忙しかった（いそがしかった）ですか。

<a id="g-past-noun"></a>

### 2. 名詞・な形容詞的過去肯否

雨です→雨でした／雨ではありませんでした；静かです→静かでした／静かではありませんでした。較口語否定為じゃなかったです，不把い形容詞直接接でした。

- 正文依據：第1、5句。
- 本文例句：昨日（きのう）は雨（あめ）でした。

<a id="g-degree-negative"></a>

### 3. あまり＋否定

あまりおいしくなかった表示不太好吃，不是完全不能吃；程度副詞修飾形容詞，和全然＋否定程度不同。

- 正文依據：第8句。
- 本文例句：リン：でも、パンはあまりおいしくなかったです。

## 舊知識回顧

回顧Day 09、11：動詞過去與形容詞過去不同；そして可添加事件，でも可轉折。第7句くて是形容詞連接，並非動詞て形。

## 理解題

1. 昨天的天氣如何？
2. リン昨天忙嗎？原因線索是什麼？
3. 午餐哪一樣受到肯定，哪一樣不太好？

## 造句／改寫練習

4. 將「忙しいです」改成過去否定。
5. 用「あまり」說昨天的麵包不太好吃。

### 選做題

6. 把「静かです」改為過去肯定。
7. 把「休みでした」改為過去否定。
8. 用くて連接「温かい／おいしい」，描述今天的湯。
