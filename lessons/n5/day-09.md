## 日文正文

1. <a id="s01"></a> 昨日（きのう）、リンは公園（こうえん）へ行きました（いきました）。
2. <a id="s02"></a> 公園で写真（しゃしん）を撮りました（とりました）。
3. <a id="s03"></a> それから、家（いえ）へ帰りました（かえりました）。
4. <a id="s04"></a> ゆき：昨日、田中（たなか）さんに会いました（あいました）か。
5. <a id="s05"></a> リン：いいえ、会いませんでした。
6. <a id="s06"></a> ゆき：写真はいつ撮りましたか。
7. <a id="s07"></a> リン：午後（ごご）三時（さんじ）に撮りました。
8. <a id="s08"></a> ゆき：公園で何か（なにか）食べました（たべました）か。
9. <a id="s09"></a> リン：いいえ、何（なん）も食べませんでした。
10. <a id="s10"></a> リン：家でパンを食べました。
11. <a id="s11"></a> そして、日本語（にほんご）の本（ほん）を読みました（よみました）。

## 繁體中文翻譯

1. 昨天リン去了公園。
2. 在公園拍了照片。
3. 然後回家了。
4. ゆき：昨天見到田中了嗎？
5. リン：沒有，沒見到。
6. ゆき：照片是什麼時候拍的？
7. リン：下午三點拍的。
8. ゆき：在公園吃了什麼東西嗎？
9. リン：沒有，什麼也沒吃。
10. リン：我在家吃了麵包。
11. 然後讀了日文書。

## 核心語塊

- 写真（しゃしん）を撮りました（とりました）
- それから、～ました
- 何（なん）も食べませんでした（たべませんでした）

## 新文法解析

<a id="g-past-verb"></a>

### 1. ～ました／～ませんでした

動詞禮貌過去肯定是ました、否定是ませんでした；不是ませんでしたです。会う的見面對象接に。

- 正文依據：第1、2、4、5句。
- 本文例句：昨日（きのう）、リンは公園（こうえん）へ行きました（いきました）。

<a id="g-sequence"></a>

### 2. それから／そして

兩者都能銜接事件；それから明確引出下一步，そして也可添加資訊。先用獨立短句連接，不急著塞長句。

- 正文依據：第3、11句。
- 本文例句：それから、家（いえ）へ帰りました（かえりました）。

<a id="g-indefinite"></a>

### 3. いつ／何か／何も＋否定

いつ問時間；何か表示某樣東西，何も搭配否定表示什麼也不。本課何か、何も的何讀なに。

- 正文依據：第6、8、9句。
- 本文例句：ゆき：写真はいつ撮りましたか。

## 舊知識回顧

回顧Day 06～08：時間に、地點で、受詞を、移動へ。第11句主角仍是リン，日文常省略連續事件中不變的主語。

## 理解題

1. リン昨天去了哪裡？
2. 照片是幾點拍的？
3. リン昨天完全沒吃東西嗎？

## 造句／改寫練習

4. 把「公園へ行きます」改為昨天的事情。
5. 否定回答「昨日、田中さんに会いましたか」。

### 選做題

6. 用いつ詢問拍照時間。
7. 填空「何も食べ（　）」，表示昨天什麼也沒吃。
8. 用それから寫兩個先後動作。
