## 日文正文

1. <a id="s01"></a> 電車（でんしゃ）の中（なか）で、三人（さんにん）は海（うみ）の話（はなし）をします。
2. <a id="s02"></a> ゆき：リンさんは日本（にほん）の海へ行った（いった）ことがありますか。
3. <a id="s03"></a> リン：いいえ、まだありません。
4. <a id="s04"></a> 田中（たなか）：わたしは去年（きょねん）、この海へ行きました。
5. <a id="s05"></a> ゆき：何（なん）をしましたか。
6. <a id="s06"></a> 田中：泳いだ（およいだ）り、写真（しゃしん）を撮った（とった）りしました。
7. <a id="s07"></a> リン：わたしも泳ぎたいです。
8. <a id="s08"></a> ゆき：今日（きょう）は風（かぜ）が強い（つよい）ですよ。
9. <a id="s09"></a> 田中：今日は泳がないほうがいいです。
10. <a id="s10"></a> リン：では、海の近く（ちかく）を歩いた（あるいた）り、お茶（おちゃ）を飲んだ（のんだ）りします。
11. <a id="s11"></a> ゆき：海の近くで、少し（すこし）休んだ（やすんだ）ほうがいいですよ。
12. <a id="s12"></a> リン：わたしも三十分（さんじゅっぷん）ぐらい歩きたいです。

## 繁體中文翻譯

1. 電車裡，三人聊起海邊。
2. ゆき：リン去過日本的海邊嗎？
3. リン：沒有，還沒有。
4. 田中：我去年去過這個海邊。
5. ゆき：做了什麼？
6. 田中：游泳、拍照等。
7. リン：我也想游泳。
8. ゆき：今天風很強喔。
9. 田中：今天最好不要游泳。
10. リン：那我就沿海散步、喝茶等。
11. ゆき：最好在海邊附近休息一下喔。
12. リン：我也想走大約三十分鐘。

## 核心語塊

- 行った（いった）ことがありますか
- ～たり～たりしました
- 泳がない（およがない）ほうがいいです

## 新文法解析

<a id="g-ta-experience"></a>

### 1. た形／～たことがあります

て形的て／で換た／だ：行って→行った、泳いで→泳いだ。たことがあります表示到現在為止的經驗，不能把某次具體昨天事件都硬改成經驗句。

- 正文依據：第2、4句。
- 本文例句：ゆき：リンさんは日本（にほん）の海へ行った（いった）ことがありますか。

<a id="g-examples"></a>

### 2. ～たり～たりします

た形＋り列舉代表性活動，最後用します／しました決定時態；不是完整列出所有事情，也不保證先後順序。

- 正文依據：第6、10句。
- 本文例句：田中：泳いだ（およいだ）り、写真（しゃしん）を撮った（とった）りしました。

<a id="g-advice"></a>

### 3. た形／ない形＋ほうがいい

做某事較好用た形＋ほうがいい，不做較好用ない形＋ほうがいい。這是建議，不等於法律禁止或絕對義務。

- 正文依據：第9、11句。
- 本文例句：田中：今日は泳がないほうがいいです。

## 舊知識回顧

回顧Day 09、15、17、20～24：過去、比較、願望、否定、て形與状態。た形不總是過去事實：休んだほうがいい是未來建議。

## 理解題

1. リン去過日本海邊嗎？
2. 田中去年做了哪些活動？
3. 為什麼建議今天別游泳？

## 造句／改寫練習

4. 詢問朋友是否去過日本。
5. 用たり列舉散步與拍照，描述昨天。

### 選做題

6. 寫「読む／書く／泳ぐ」的た形。
7. 建議對方今天早點睡。
8. 用兩句說自己的經驗，再說想做的事，可虛構。
