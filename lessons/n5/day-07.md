## 日文正文

1. <a id="s01"></a> 今日（きょう）は休み（やすみ）です。
2. <a id="s02"></a> リン：銀行（ぎんこう）へ行きます（いきます）。
3. <a id="s03"></a> ゆき：わたしも駅（えき）に行きます。
4. <a id="s04"></a> リン：駅までどうやって行きますか。
5. <a id="s05"></a> ゆき：バスで行きます。
6. <a id="s06"></a> リンはゆきとバスに乗ります（のります）。
7. <a id="s07"></a> バスは九時（くじ）に駅に着きます（つきます）。
8. <a id="s08"></a> 銀行は駅の前（まえ）にあります。
9. <a id="s09"></a> リン：帰り（かえり）もバスですか。
10. <a id="s10"></a> ゆき：いいえ、歩いて（あるいて）帰ります（かえります）。
11. <a id="s11"></a> リン：わたしも一緒に（いっしょに）帰ります。

## 繁體中文翻譯

1. 今天放假。
2. リン：我要去銀行。
3. ゆき：我也要去車站。
4. リン：到車站要怎麼去？
5. ゆき：搭巴士去。
6. リン和ゆき搭上巴士。
7. 巴士九點到車站。
8. 銀行在車站前面。
9. リン：回程也搭巴士嗎？
10. ゆき：不，我走路回去。
11. リン：我也一起回去。

## 核心語塊

- どうやって行きます（いきます）か
- バスで行きます（いきます）
- 一緒に（いっしょに）帰ります（かえります）

## 新文法解析

<a id="g-destination"></a>

### 1. 目的地に／へ・乗り物に乗る

行く的目的地可用に或へ，へ讀え。乗る的搭乘對象用に，不能因此一律換へ；着く通常以に標到達點。

- 正文依據：第2、3、6、7句。
- 本文例句：リン：銀行（ぎんこう）へ行きます（いきます）。

<a id="g-transport"></a>

### 2. どうやって／交通工具で

どうやって問方法；交通工具＋で回答如何移動。步行常用歩いて，不用歩いてで。

- 正文依據：第4、5句。
- 本文例句：リン：駅までどうやって行きますか。

<a id="g-with"></a>

### 3. 人と／一緒に

と表示同行者；一緒に表示一起。人已知時可省略同行者。第10句歩いて先作「步行」語塊，Day 21學て形。

- 正文依據：第6、11句。
- 本文例句：リンはゆきとバスに乗ります（のります）。

## 舊知識回顧

回顧Day 04、06：場所、時點、ません；から／まで也可標路程起訖。銀行與超市相鄰且位於車站前，後續沿用此生活圈。

1. 兩人如何到車站？
2. リン到車站後的目的地是什麼？
3. ゆき回程仍搭巴士嗎？
