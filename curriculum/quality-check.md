# 本輪教材檢查紀錄

## 完成範圍

- 30篇成人生活情境課文、341句正文，每篇11～12句。
- 30份獨立答案，每課3題理解、2題產出、3題選做，共240題。
- 另有3輪、每輪18個延伸複習任務，屬課後練習，不計入正文與每日8題。
- 已同步共同規則、兩份專案skill、模板、課程目錄及文法／單字索引。
- 30個「學習後問題與訂正」區保留空白，既有問題與學習進度沒有代填。

## 實際檢查

執行 `python3 scripts/validate_course.py` 通過：課數、正文句數、翻譯編號、每日8題、答案8題、十個固定區塊、答案分檔、相對連結、正文與文法錨點、簡單skill前置資料。

執行 `git diff --check` 通過。另逐課檢視正文及答案，修正未教的條件句、過重的雙重否定、漢字詞首次讀音、前後翻譯與題目引用；這是編寫檢查，不是母語教師背書或正式考試效度驗證。

skill-creator附帶的 `quick_validate.py` 曾執行，但目前Python環境缺少PyYAML，因此未成功跑完；已以專案檢查器核對這兩份skill使用的簡單name／description格式、命名與引用，未宣稱原驗證器通過。

## 覆蓋與仍需回收之處

[84項參照核對](n5-coverage.md)均有教學對應，但其中9項為解析中的口語／書面變體辨識，非各自的正文實例。其餘仍需逐形式分辨，不把「同組文法」當成各用法全都出現。

正文後課重現仍有不足3課的項目，詳見核對表；延伸複習提供具體回收任務，但尚未作答，不能當成已完成的跨課正文重現或熟練證據。沒有聲稱所有核心單字均重現四次。

此輪完成的是可開始學習的整套教材。之後根據真實疑問與作答，在使用者說「整理」後記錄並安排複習；是否延緩進度或修改已完成課文，先與使用者討論。
